# Smart Duration Field for Jira

Enter, display, and search Jira durations using familiar values such as `2w`,
`5d`, `4h`, or `30m`.

Smart Duration Field stores durations as seconds while presenting a format that
people can easily understand and edit.

[Create your first field](getting-started.md){ .md-button .md-button--primary }
[JQL reference](jql.md){ .md-button }

## Key features

- Enter weeks, days, hours, minutes, and seconds, including combined values
  such as `1w 2d 4h 30m`.
- Use Jira's global working calendar and Time display format.
- Search duration values with normal JQL comparisons.
- Compare Smart Duration values with Jira Time Spent.
- Add several estimates into one read-only Smart Duration Total.

See [Getting started](getting-started.md) for setup, or use the navigation to
open global settings, Smart Duration Total, and the full JQL reference.
