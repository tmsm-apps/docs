# TMSM Jira Apps

Choose the Jira Cloud app you want to learn about.

## Smart Duration Field

Enter, display, and search Jira duration values using familiar expressions such as `2w`, `5d`, `4h`, or `30m`. It can also compare a duration with Jira Time Spent and calculate a total from several duration fields.

[Open Smart Duration Field documentation](getting-started.md){ .md-button .md-button--primary }

## FieldWas

Search for work items that held a custom-field value in the past. For example, find work that was once assigned to a team, had a particular label, or was planned for a release during a selected period.

[Open FieldWas documentation](fieldwas/index.md){ .md-button .md-button--primary }

!!! note

    Both apps are Jira Cloud Forge apps. Documentation may evolve while a feature is in development or pilot use.
